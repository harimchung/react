## Day 4을 진행하며 느낀점

### 1. props drilling vs context
- 무조건 props 형태가 능사는 아니다!
- 불필요한 props drilling 을 계속 해줘야할 수도 있다
- 하지만 부모, 자식간의 데이터 흐름이 확실한 때 규모가 작은 프로젝트에서 사용

- 그렇다고 context 가 만든해결책은 아니다.
- context가 변화하면 쓰인곳이 전부 re-render 되는 불필요한 과정을 거치게 된다.
- 하지만 전역에서 관리하기 떄문에 필요한 곳에서 뽑아 쓸 수 있다는 장점이 있다.

- 특히 context로 분리해서 상태와 액션을 분리하면 불필요한 리렌더링을 줄일 수 있다.
